📌 Описание проблемы  
   
Пользователи, вынужденные переходить с Windows на Linux (по причинам недоступности ПО, проблем с лицензиями или ради приватности), сталкиваются с жестким порогом входа: отсутствие привычного интерфейса, необходимость работы в терминале, сложность настройки драйверов и запуска привычных .exe программ. Существующие дистрибутивы (включая базовый Linux Mint) предоставляют мощную систему, но не решают бытовые проблемы мигранта «из коробки».  
   
Цель проекта: Создать кастомную операционную систему Berry OS, которая решает главные боли пользователя Windows и предоставляет готовую, безопасную и красивую среду без необходимости использования командной строки.   
   
✅ Реализованные задачи  
   
В ходе разработки (в среде Cubic на базе Linux Mint 22) были выполнены следующие задачи:  
1. Глубокая кастомизация системы (Branding):  
	• Изменена загрузочная запись GRUB («Start BerryOS» вместо Linux Mint).  
	• Полностью заменен экран загрузки Plymouth (заменены все кадры анимации на кастомный логотип).  
	• Заменена иконка главного меню (апплета Cinnamon) через системные конфиги и glib-compile-schemas.  
	• Установлены кастомные обои на рабочий стол, экран входа (LightDM) и экран загрузки.  
2. Создание собственного интерфейса и утилит (GUI):  
Написаны приложения на Python 3 / PyQt6 с использованием QtAwesome и темной темы QSS:  
	• Berry Command Center — главный хаб системы (мониторинг CPU/RAM, App Store, Doctor).  
	• Berry App Store — установщик софта с выбором источника (APT / Flatpak).  
	• Berry Cleaner — утилита безопасной очистки кэша и логов.  
	• Berry Drivers — графический установщик драйверов (Nvidia, кодеки, принтеры).  
	• Berry Updater — центр обновлений с потоковым выводом stdout прямо в GUI (без черных окон терминала).  
	• Berry Theme Manager — переключатель GTK-тем (Zorin + Papirus) и кастомный рендер превью.  
	• Berry Media Player — темный медиаплеер с поддержкой видео и аудио.  
	• Berry System Monitor — диспетчер задач с графиками и возможностью завершения процессов.  
3. Инструменты миграции и совместимости:  
	• Berry Migrator — утилита для автоматического поиска NTFS-разделов Windows и переноса файлов (Desktop, Documents, Downloads) в домашнюю папку.  
	• Berry Windows Bridge — графическая обертка для Wine. Позволяет запускать .exe, настраивать версию Windows (через winetricks) и автоматически создавать .desktop ярлыки.  
	• Настроена системная ассоциация файлов: двойной клик по .exe автоматически запускает Wine (xdg-mime).  
4. Безопасность и приватность:  
	• Berry Antivirus — сканер файлов на базе ClamAV и YARA (через clamd и yara-python). График угроз рисуется через кастомный QPainter.  
	• Настроены горячие клавиши (Win+Shift+S для скриншотов, Win+E для проводника, Alt+Shift для раскладки) через gschema.override (системный уровень).  
5. Глобальная настройка окружения:  
	• Интеграция иконок Papirus и GTK-темы Zorin.  
	• Создание файла автозагрузки (автозапуск OOBE) через /etc/skel/.  
	• Написание Bash-скриптов для автоматизации развертывания в chroot-окружении.   
   
🛠️ Техническое решение  
   
Среда сборки: Cubic (Custom Ubuntu ISO Creator), chroot-окружение.  
Базовая ОС: Linux Mint 22 (Cinnamon).  
Стек технологий: Python 3.12, PyQt6 (UI), psutil (мониторинг), subprocess (системные вызовы), Git, Bash, Wine, ClamAV, YARA.  
   
Ключевые архитектурные решения:  
1. Изоляция интерфейса от терминала:  
Все утилиты используют subprocess.Popen с перехватом потоков stdout и stderr. Это позволяет в реальном времени отображать логи установки/очистки внутри виджетов QTextEdit, не открывая сторонние окна терминала.  
2. Многопоточность (QThread):  
Тяжелые операции (сканирование антивирусом, обновление системы, копирование данных мигратором) вынесены в фоновые потоки. Это исключает зависание GUI («Not Responding») во время длительных операций.  
3. Управление настройками на системном уровне:  
Поскольку gsettings и dconf не работают в среде chroot (нет D-Bus/X11), настройки (темы, хоткеи, иконки) применяются через создание файлов .gschema.override в /usr/share/glib-2.0/schemas/ с последующей компиляцией glib-compile-schemas.  
4. Ресурсная безопасность:  
Для снижения нагрузки на CPU внедрены кастомные иконки через QtAwesome вместо растровых изображений, а тяжелые системные вызовы минимизированы. При сборке ISO используется сжатие lz4 для предотвращения ошибок чтения ядра (invalid magic number).
